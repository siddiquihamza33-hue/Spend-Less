# Spend Lens

A private credit card statement reader. Open `index.html` in Chrome, upload a CSV, Excel or PDF statement (password-protected PDFs work), and see where the money went. Everything runs in the browser; nothing is uploaded.

## Use it

Open `index.html` in Chrome. It is a single self-contained file that needs no internet. Your statements stay saved in the browser between visits. Served from a web address (the `apps/web/dist/` folder), it can also be installed as an app and opened offline.

## Work on it

Needs Node 20+ and pnpm.

```bash
pnpm install        # once
pnpm dev            # work on the app with live reload
pnpm check          # type-check, run all tests, rebuild index.html
```

More in [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md). Architecture and roadmap: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Layout today (phase 3 of the roadmap)

```text
spend-dashboard/
├── index.html                 # GENERATED by `pnpm build` — the whole app in one file
├── apps/web/                  # the app source: React + Vite + TypeScript
├── lib/spendlens-core.js      # GENERATED — logic bundle for the real-statement check script
├── packages/
│   ├── ui/                    # design: styles, icons, focus trap
│   ├── core/                  # parsing, currency, categories, formatting, analytics (+ tests)
│   └── banks/                 # one adapter per statement format: HBL, generic PDF, CSV/Excel (+ fixtures, tests)
├── scripts/                   # build, browser entry, local real-statement check
└── docs/
```
