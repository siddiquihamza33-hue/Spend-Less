# Spend Lens

A private credit card statement reader. Open `index.html` in Chrome, upload a CSV, Excel or PDF statement (password-protected PDFs work), and see where the money went. Everything runs in the browser; nothing is uploaded.

## Use it

Open `index.html`. Keep the `lib/` folder next to it — it holds the product logic (`lib/spendlens-core.js`).

## Work on it

Needs Node 20+ and pnpm.

```bash
pnpm install        # once
pnpm check          # type-check, run all tests, rebuild lib/spendlens-core.js
```

More in [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md). Architecture and roadmap: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Layout today (phase 1 of the roadmap)

```text
spend-dashboard/
├── index.html                 # the app: UI, pages, storage, import flow
├── lib/spendlens-core.js      # GENERATED by `pnpm build` — product logic for the browser
├── packages/
│   ├── core/                  # parsing, currency, categories, formatting, analytics (+ tests)
│   └── banks/                 # one adapter per statement format: HBL, generic PDF, CSV/Excel (+ fixtures, tests)
├── scripts/                   # build, browser entry, local real-statement check
└── docs/
```
